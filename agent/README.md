# Путь А — ElevenLabs в тестовой странице Ideal Systems

## Подтверждённый источник
GitHub: Vlad8897/Info, ветка ideal-systems-elevenlabs-preview.
Исходный базовый файл: ветка ideal-systems-support-preview/index.html.
Новая ветка не меняет основную, не обновляет DNS и не активирует Stripe.

## Что уже содержится
index.html — тестовая страница с четырьмя языками и виджетом, который активируется только после ручного ввода публичного Agent ID и подтверждения посетителя.
agent/knowledge-public-ru.md — подготовленная база публичных знаний без закрытых документов.
agent/system-prompt-ru.md — инструкции поведения модели.
agent/voice-tests-ru.md — условия испытания.

## Что сделать владельцу в ElevenLabs
1. Открыть https://elevenlabs.io/app/conversational-ai и войти или создать аккаунт (на бесплатном плане).
2. Создать нового ElevenAgents агента; тип — голосовой помощник сайта.
3. В настройках установить имя Ideal Systems — Public Preview.
4. В поле System prompt вставить agent/system-prompt-ru.md (если предусмотрено стартовое сообщение, выбрать первый текст на нужном языке).
5. В разделе Knowledge Base → Add Document загрузить agent/knowledge-public-ru.md либо вставить текст.
6. Выбрать голос с качественным произношением русского и проверить немецкий, английский, украинский. Первоначальный язык/автоопределение зависит от настройки ElevenLabs.
7. Не добавлять инструменты CRM, телефонии, Stripe или Google Drive: они ещё не проверены.
8. Для встроенного виджета согласно документации ElevenLabs нужен публичный агент (Authentication выключена), с ограничением Allowlist на тестовый домен в разделе Security. На бесплатном испытании не указывать рабочий домен без необходимости.
9. Скопировать Agent ID. НЕ копировать API key.
10. Открыть тестовую страницу по HTTPS/localhost, вставить Agent ID, отметить подтверждение, нажать «Подключить для испытания».
11. Разрешить доступ к микрофону в браузере, проверить звук и разговор. Следить за остатком минут в ElevenLabs.
12. После настройки постоянного домена перенести Agent ID в утверждённую конфигурацию сайта, не хранить секреты в коде браузера.

## Дополнительные ограничения
Если Cloudflare Pages не связан с GitHub, новая ветка не появится на публичном сайте автоматически: сначала развернуть preview.
Agent ID не является API-ключом, но публиковать активный агент без доменного ограничения и контроля затрат рискованно.
История разговоров и персональные данные требуют отдельных сроков, оснований обработки и политик. До оформления не собирать контакты и не включать сторонние инструменты.
Первые испытания проводить с вымышленными данными, без оплат и персональных файлов.
Люди могут отказаться от общения с агентом без потери доступа к основной странице.
Оригинальные исходники и прежняя ветка не удаляются и не переписываются.
